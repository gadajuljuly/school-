# תל"א / תח"י

אפליקציה לבניית תוכנית לימודים אישית (תל"א / תח"י) לתלמידים בחינוך המיוחד.

**כתובת האפליקציה:** https://gadajuljuly.github.io/tala/

## איך עובדים
1. **פרטי התלמיד/ה** – פרטים אישיים, צוות, תמיכות, רקע והתאמות.
2. **מיפוי והערכה** – לכל מיומנות הערכה 1–5 והערה, ונתונים כלליים לכל תחום.
3. **בנה את התוכנית** – האפליקציה בונה את התל"א מהמיפוי ומאגר המטרות.
4. **הורדה כ-Excel / הדפסה** – לפי פורמט התל"א של מת"יא או תבנית בית הספר.

## קבצים
- `materials.js` – מאגר המטרות, פריטי המיפוי, כלי ההערכה ותוכנית הלימודים.
- `app.js` – האפליקציה. `xlsx.js` – יצירת קובצי Excel.
- `cloud.js`, `config.js`, `supabase/schema.sql` – שמירה בשרת (Supabase), כניסה עם מייל ומסך ניהול.
  כש-`config.js` ריק, הנתונים נשמרים רק במכשיר.
